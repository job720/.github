# Job720

**[Job720](https://job720.com)** 是面向 **AI / 芯片 / 新能源 / 机器人 / 无人机** 等前沿行业的求职信息枢纽：
把招聘方在自己官网上**公开发布**的在招岗位直采过来，做筛选、比对、JD 分节阅读和收藏。

## 我们做什么

- 只采**公开**内容：招聘方自有招聘站点上无需登录、无需签名就能看到的页面
- 每天 **07:10 与 19:10**（北京时间）各更新一次，岗位上下线逐日留痕
- 每个岗位页都写明**数据截至时刻**与**采集口径**，数字从库里现算，不写死

## 我们的立场

- 不替招聘方说话：站内所有统计都是"我们数出来的"，口径和缺口一起写

## 看这里

- 在招岗位：**https://job720.com**
- 岗位观察（每天的数据变化与口径说明）：**https://job720.com/observe**
- 博客 / 行业求职问答：**https://job720.com/blog**
- 给机器读的口径说明：**https://job720.com/llms.txt**
